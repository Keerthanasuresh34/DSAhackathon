Archival Notation Protocol
  • Token Separation: Separate each royal lineage node and missing branch with a single space.
  • Vanishing Heir Marker (#): Use # to denote a null child or missing ancestral branch.
  • Preorder Traversal Sequence: Inscribe strictly in order: Root → Left Subtree → Right Subtree.
  • Example: A B # D # # C # # (A is root; A has left B and right C; B has no left child, right child D; D and C are leaves).
